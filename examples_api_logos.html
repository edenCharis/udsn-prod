🎨 API des Logos - Exemples d'intégration

Cette page montre comment utiliser l'API des logos pour charger les logos dynamiquement via AJAX.

Endpoints disponibles

1. Obtenir le logo par défaut

GET /php/api_logos.php?action=get_default

2. Obtenir le logo d'une université

GET /php/api_logos.php?action=get_university_logo&univ_code=1

3. Obtenir le logo de l'utilisateur connecté

GET /php/api_logos.php?action=get_user_logo (Nécessite une session authentifiée)

4. Lister tous les logos

GET /php/api_logos.php?action=list_all

5. Obtenir le favicon

GET /php/api_logos.php?action=get_favicon GET /php/api_logos.php?action=get_favicon&session=1 (avec session)

Exemples de code

JavaScript - Récupérer et afficher le logo


// Charger le logo par défaut
fetch('/php/api_logos.php?action=get_default')
    .then(response => response.json())
    .then(data => {
        if (data.success) {
            document.querySelector('img.logo').src = data.data.logo;
        }
    });

// Charger le logo d'une université spécifique
fetch('/php/api_logos.php?action=get_university_logo&univ_code=1')
    .then(response => response.json())
    .then(data => {
        if (data.success) {
            console.log('Logo:', data.data.logo);
            document.querySelector('img.logo').src = data.data.logo;
        } else {
            console.error(data.message);
        }
    });

jQuery - Version simplifiée


$.ajax({
    url: '/php/api_logos.php',
    data: { action: 'get_university_logo', univ_code: 1 },
    success: function(response) {
        if (response.success) {
            $('.logo').attr('src', response.data.logo);
        }
    }
});

Boucler sur tous les logos


fetch('/php/api_logos.php?action=list_all')
    .then(response => response.json())
    .then(data => {
        if (data.success) {
            Object.entries(data.data).forEach(([univCode, logoPath]) => {
                console.log(`Université ${univCode}: ${logoPath}`);
            });
        }
    });

Intégration dans une page HTML


<!-- Logo dynamique -->
<img id="main-logo" class="logo" src="" alt="Logo">

<script>
    // Charger le logo au chargement de la page
    document.addEventListener('DOMContentLoaded', function() {
        fetch('/php/api_logos.php?action=get_default')
            .then(r => r.json())
            .then(d => {
                if (d.success) {
                    document.getElementById('main-logo').src = d.data.logo;
                }
            });
    });
</script>
