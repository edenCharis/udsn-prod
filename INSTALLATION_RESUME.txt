🚀 DÉMARRAGE RAPIDE
═══════════════════════════════════════════════════════════════════════════

POUR LES ADMINISTRATEURS:
  1. Accédez à: /administrateur/parametre_logos.php
  2. Uploadez un logo pour chaque université
  3. Les changements s'appliquent immédiatement
  4. Vérifiez sur la page de connexion

POUR LES DÉVELOPPEURS:
  1. Incluez config/logo_config.php dans vos pages
  2. Utilisez: $logoConfig->getDefaultLogo()
  3. Ou utilisez les fonctions de php/lib.php
  4. Voir examples_api_logos.html pour les exemples

POUR LES TESTEURS:
  1. Accédez à: /test_logos.php
  2. Vérifiez que tous les tests passent
  3. Testez l'upload d'un logo
  4. Vérifiez l'affichage après connexion

💡 POINTS IMPORTANTS
═══════════════════════════════════════════════════════════════════════════

• Le dossier administrateur/logo/ est créé automatiquement à la première 
  utilisation. Pas besoin de le créer manuellement.

• La base de données doit contenir la colonne 'logo' dans la table 'univ'.
  Si elle n'existe pas, exécutez:
  ALTER TABLE `univ` ADD COLUMN `logo` VARCHAR(255) DEFAULT NULL;

• Les fichiers anciens restent dans le dossier pour l'historique. Vous 
  pouvez les supprimer manuellement si nécessaire.

• La session $_SESSION['logo_univ'] est définie automatiquement lors de 
  la connexion via php/routeur.php.

• Le cache de la classe LogoConfig est vidé automatiquement après chaque 
  upload.
